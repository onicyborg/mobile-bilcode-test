# Siklus mobile

Direction is inherited from the user's accepted Siklus website, not a new brand proposal.

ENERGY 3 / RHYTHM 4 / MOTION 2. A calm civic reporting tool with a clear action and tangible report evidence. Forest #173D2E, lime #C8EE88, warm paper #F5F6F1, ink #172820. White surfaces, readable system sans, 8dp spacing increments, 12dp field radii, 20dp grouped surface radii. Dark mode uses deep forest surfaces and light text, not inverted colors.

Dashboard: a compact brand header, a strong forest reporting panel, real status counts and recent report rows with actual photos. This makes the next action and existing progress visible without promotional sections. Report creation is a focused scrolling form with numbered photo/location/description sections; location uses a real selectable map. Lists prioritize photo, description, status and time. Detail prioritizes evidence, category estimate, location and the real status timeline.

Lime marks the primary reporting action and selected navigation. Forest anchors identity and headings. Status colors carry visible text. Material outlined icons have task-specific meaning. The existing text wordmark Siklus is reused; no new logo, people imagery or decorative asset is generated. Photo content comes exclusively from actual reports or user selections.

Motion is limited to Material navigation, progress feedback and system-respecting page transitions. Bottom navigation has three destinations: Beranda, Laporan, Akun. Inputs retain labels and error messages; primary actions are at least 52dp tall. Empty, permission-denied, offline, retry and loading states are designed as part of each workflow.

The Siklus wordmark keeps a fixed visual size as the existing brand mark; its text remains available to screen readers. All content, forms and controls retain system text scaling.
